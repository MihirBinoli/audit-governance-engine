# Enterprise Audit & Governance Workflow Engine

An enterprise-grade platform designed for managing multi-tier compliance workflows (Maker-Checker architecture) with integrated real-time automated SLA escalation triggers.

## Monorepo Architecture
- `/backend`: Spring Boot REST API application implementing Clean Architecture.
- `/frontend`: Angular enterprise application utilizing modular state management.
- `/docs/architecture`: System design specifications, schema definitions, and sequence diagrams.
